How to Use – Talking Clock & Alarm App

This guide explains how to use each tab and how Settings affect the app.

Clock Alarms Focus Water Health (Medication) Yoga Settings

Clock – Talking Clock

What you see

Current time, a Start/Stop Talking Clock Service Slider button for the Talking Clock service, and (when the service is running) a Settings card with announcement and quiet-hours options.

How to turn on

  • Open the Clock tab with Show Seconds – Toggle to include seconds in the on-screen time (e.g. 14:32:05).
  • Tap the Talking Clock Service Slider to Start Talking Clock. The service starts and will announce the time at the interval you set.

How to edit (when service is running)

  • Announcement Interval – Dropdown: how often the clock speaks (e.g. 1 min, 5 min, 15 min, 1 hr, 2 hrs). Default is every 60 minutes.
  • Quiet Hours Interval 1 – Start and End time (time picker + slider). During this range the clock does not announce (e.g. 22:00–07:00 for night). Always active.
  • Quiet Hours Interval 2 – Toggle on to use a second quiet window (e.g. lunch 12:00–13:00). Same Start/End time pickers and sliders.

Note: Changes apply immediately while the Talking Clock service is running.

Alarm – Alarms

What you see

Title "Alarms", a + button to add an alarm, and a list of your alarms. When an alarm is ringing, a dismiss card appears at the top.

How to add

  • Open the Alarm tab.
  • Tap the + (FAB) button.
  • In the dialog: set Alarm Details , optional Message, and Talking Alarm enable/disable Slider button. Tap Add Alarm.
  • A Repeat ON slider button to add recurring days if it is a recurring alarm

How to edit

  • Tap the Edit (pencil) icon on an alarm.
  • Change time, Message, enabled state, or Repeat ON/ Days of the week, then save.

Alarms use the system alarm; they can fire even when the app is closed (subject to system/battery rules).

Focus – Focus Timers

What you see

Title "Focus Timers", "My Timers" with a + button, an active timer card (when one is running) with progress and work/break phase, and a list of your saved timers.

How to add

  • Open the Focus tab.
  • Tap the + button next to "My Timers".
  • In the dialog: set work duration, break duration, and cycles. Name the timer if you want. Tap Add.

How to edit

  • Tap Edit on a timer in the list to change work/break/cycles or name.

Start a timer from the list to see the running screen with progress. You can pause, resume, or stop. At the end of work/break phases you get a notification (respects Settings).

Water – Water Reminder

What you see

Title "Water Reminder". If no reminder exists: empty state with "Add Water Reminder". If one exists: a card with countdown, progress bar, toggle, edit, and delete.

How to add

  • Open the Water tab.
  • If none exists: tap Add Water Reminder.
  • In the dialog: set interval (minutes, e.g. 15 or 60), optional start time and end time (e.g. 09:00–21:00), and message. You can enable Speak message (TTS). Tap to save.

How to edit

  • On the water card, tap Edit. Change interval, time range, message, or "Speak message", then save.

Only one water reminder is used. The countdown and next notification are driven by WorkManager so they keep working after device is idle but The notification is not triggered if device is idle. This is unlike the alarm notifications

Health – Medication Reminders

What you see

Title "Medication Reminders", "My Medications" with a + button. Either an empty state or a list of medication reminders with toggle, edit, and delete.

How to add

  • Open the Health tab.
  • Tap the + button.
  • In the dialog: set name, dosage , message with enable Speak message if you want TTS, Reminder Alarm Time (e.g. 08:00, 20:00), and repeat days. Tap to save.

How to edit

  • Tap Edit on a medication reminder to change any of the above.

Yoga – Yoga Timers

What you see

Title "Yoga Timers", "My Yoga Timers" with a + button. When a timer is running: active timer card with time left, current pose, progress, pause/resume/stop. Below: list of saved yoga timers.

How to add

  • Open the Yoga tab.
  • Tap the + button.
  • In the dialog: set number of poses, interval (seconds between poses), and optional name. Tap to save.

How to edit

  • Tap Edit on a yoga timer in the list to change poses, interval, or name.

Tap Start on a timer to run it. The app shows progress and rings a bell at each pose interval. You can pause or stop.

Settings

Open the Settings tab (gear icon in the bottom bar) to see app-wide options and About.

App Settings

Each option affects which features can make sound, vibrate, or show notifications.

Notifications
Enable or disable push notifications.
Affects: Water reminder, Medication reminders, Focus timer phase notifications. When off, no reminder/phase notifications are shown.
Sound
Enable or disable sounds for alarms and reminders.
Affects: Talking Clock, Alarm sound, Focus timer phase alerts, Water/Medication reminder notification sound, Yoga bell, notification channel sounds. When off, notifications and alarms may be silent (or vibration-only if Vibration is on).
Vibration
Enable or disable vibration for alarms and reminders.
Affects: Alarm vibration, Focus timer phase vibration, Water/Medication reminder notification vibration. When off, only sound (if Sound is on) is used.
Dark Mode
Switch the app to a dark theme.
Affects: Entire app UI (all tabs and screens). No effect on alarms or reminder behavior.
